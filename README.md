# Smart Study Planner – User Stories

## User Story 1 – Create a Study Task

As a student, I want to create a study task with a deadline, so that I can organize my study schedule.

## User Story 2 – View Upcoming Tasks

As a student, I want to view my upcoming study tasks and deadlines, so that I can plan my study time effectively.

## User Story 3 – Complete a Study Task

As a student, I want to mark study tasks as completed, so that I can track my progress and see what I have accomplished.

## User Story 4 – Receive Study Reminders

As a student, I want to receive reminders for upcoming study tasks, so that I do not miss important deadlines.

## User Story 5 – View Task Details

As a student, I want to view the details of a study task, so that I can see all the information I need before starting it.

## User Story 6 – Edit a Study Task

As a student, I want to edit my study tasks, so that I can update information when my study plans change.

## User Story 7 – Track Study Progress

As a student, I want to view my study progress by subject, so that I can identify areas where I need to improve.

## User Story 8 – Manage Notification Preferences

As a student, I want to customize my notification and reminder preferences, so that I receive reminders at times that are convenient for me.

## User Story 9 – Access Tasks Offline

As a student, I want to access and manage my study tasks when I am offline, so that I can continue studying without an internet connection.
